# SmartAnalyticsPlatform

SmartAnalyticsPlatform es una plataforma profesional para análisis financiero, trading algorítmico e inteligencia artificial.

## Características

* FastAPI
* SQLAlchemy 2.0
* Machine Learning
* OpenAI
* TradingView
* MetaTrader 5
* Backtesting
* Dashboard Web
* Docker
* GitHub Actions
